# PFO1 - Landing de Portafolio Personal

## 📌 Descripción

Este proyecto corresponde a la PFO1 de la materia **Desarrollo de Sistemas Web - Front End**.

Se trata de una landing page de portafolio personal desarrollada utilizando **HTML y CSS**. El objetivo es presentar mi perfil, mis habilidades, algunos de mis proyectos y diferentes formas de contacto.

## 👩‍💻 Sobre el proyecto

La landing incluye las siguientes secciones:

- Inicio
- Sobre mí
- Habilidades
- Proyectos
- Contacto

También incluye un enlace visible a mi perfil de GitHub y enlaces a algunos de mis proyectos.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts
- Flexbox
- CSS Grid
- Diseño responsive
- Git
- GitHub
- Vercel

## 🎨 Decisiones de diseño

Elegí una estética moderna y sencilla, utilizando principalmente tonos violetas y fondos claros.

Utilicé tarjetas para presentar las habilidades y los proyectos, buscando organizar la información de manera clara y facilitar la lectura.

Para la adaptación a dispositivos móviles utilicé una media query que modifica la distribución de las tarjetas y el menú de navegación.

También incorporé transiciones en las tarjetas y botones para generar una interacción visual suave.

Utilicé variables CSS para centralizar los principales colores del diseño y facilitar futuros cambios de estilo.

Durante el desarrollo de esta PFO utilicé **ChatGPT** como herramienta de asistencia.

### Para qué utilicé IA

Utilicé la herramienta principalmente como apoyo durante el proceso de desarrollo para:

- Resolver dudas sobre HTML y CSS.
- Comprender el uso de etiquetas semánticas.
- Revisar la estructura del código.
- Recibir sugerencias para mejorar el diseño responsive.
- Comprender el uso de Flexbox y CSS Grid.
- Revisar errores y realizar mejoras en el código.
- Orientarme en el proceso de conexión del proyecto con GitHub.
- Recibir orientación para la publicación del proyecto en Vercel.

### Plan utilizado

Utilicé el plan gratuito de ChatGPT.

### Experiencia previa

Ya tenía conocimientos previos de programación y desarrollo web, incluyendo HTML, CSS y JavaScript. También tenía experiencia utilizando Visual Studio Code y GitHub.

La IA fue utilizada como herramienta de apoyo y no como reemplazo del aprendizaje.

Todo el código fue revisado y adaptado durante el desarrollo del proyecto.
